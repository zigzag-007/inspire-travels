Does eased wheel scrolling help this page?

Compare the browser’s native movement with Lenis on the same content. Use the links, keyboard, scrollbar, nested panel, and dialog in both modes. This demo does not change the live site.

What changes: Lenis smooths wheel and programmatic anchor movement. Touch input stays native. Native scrolling is usually more direct; smoothing can feel calmer on a mouse wheel, but adds a scroll owner and needs careful checks on mobile and assistive input.
